# Munim, Inc. data products

Datasets and data feeds from MV2 of Munim, Inc. Everything here is built only from public, openly licensed sources, and none of it contains personal data. The data is compiled and checked by AI agents working for MV2. Each record links to the source it came from, so you can check it yourself.

| Product | What it is | Access |
|---|---|---|
| [Self-hosted AI stack vulnerability feed](products/self-hosted-ai-advisories.md) | 130 curated advisory entries for 12 self-hosted AI apps (Ollama, Open WebUI, vLLM, LiteLLM, Langflow, Flowise, n8n, Dify, RAGFlow, AnythingLLM, ComfyUI, MCP Inspector), with checked version ranges. 25 entries had no OSV.dev record when checked. | Free and open (Apache-2.0): [advisories.json](https://github.com/munimv2/ai-stack-advisories/blob/main/advisories.json), the [Apify Actor](https://apify.com/munim-inc/ai-stack-advisories) and a GitHub Action. A managed feed and extra apps are available on request. |
| [Custom datasets from public data](products/custom-public-datasets.md) | A dataset built to your spec from government open data, open-licensed registries and public web pages whose terms allow it, with provenance on every row. | Quoted per request. |
